# DiaScript
SNUGDC 스타터 프로젝트

키보드 궤적으로 마법을 시전하는 탑다운 액션 게임 (현재 프로토타입).

## 핵심 아이디어
키패드(Y U I O P / H J K L ; / N M , . /)의 키를 순서대로 눌러
궤적의 형태(V, Λ, O, X 등)를 인식하고 그에 맞는 마법을 발동.
붉은 마룡(공격)과 푸른 마룡(제어)을 전환하며 같은 형태로 다른 효과를 냄.

## 플레이 방법
| 키 | 동작 |
|---|---|
| WASD | 이동 |
| Shift | 대쉬 (무적) |
| Q / E | 붉은/푸른 마룡 전환 |
| 스펠키 입력 → Enter | 마법 발동 |
| 마지막 키 재입력 | 마법 발동 |
| 첫 번째 키 재입력 | 입력 취소 |
| Esc | 입력 취소 |

## 구현된 마법 형태
| 형태 | 인식 조건 | 붉은 효과&지속시간&공격력 | 푸른 효과&지속시간&공격력 | 쿨타임 |
|---|---|---|---|---|
| V | 양 끝 같은 행, 중간이 낮은 행 | 폭발 수렴 (꼭짓점으로 몹들 당김+스턴 0.5초+피해) 1초 60 | 기절 수렴(꼭짓점으로 몹들 당김+스턴 1초+피해) 1초 40 | 2초 |
| Λ | 양 끝 같은 행, 중간이 높은 행 | 폭발 수렴 1초 60 | 기절 수렴 1초 40 | 2초 |
| O | 3→2→1→2행 순환 | 슬로우(적30%감속)+지속 피해 2초 8 | 스턴+지속 피해 3초 5 | 전투 시작 시 3초, 이후 4초 |
| X | 3층 2개→2층 1개→1층 2개, 중간이 사이 | 90 | 60 | 경로 전환+기절 | 전투 시작 시 6초, 이후 5초 |
| 점 | 같은 키패드 2번 연속 입력 | 공격 40 | 공격 30 | 0.3초 |
| 일반 공격선 | 위 외 모든 입력 | 앞으로 나아가는 공격선 40 | 벽 20 | 0.5초 |

+붉은 마룡의 자해딜은 5로 고정

## 구현된 몬스터
- **멧돼지**: idle→준비(타원)→돌진(삼각형) 사이클, V/O로 돌진 취소
- **거미**: 소환 위치에 십자 거미줄 고정, 접촉 시 슬로우
- **부유정령**: 랜덤 부유, 주기적 투사체 발사
- **분열슬라임**: 사망 1.5초 후 2분열 (붉은O=4분열, 푸른O=분열 없음)
- **뿔개미**: 2마리가 선으로 연결, I/X 용언으로 분리
- **폭탄벌레**: 사망 시 범위 폭발
  
## 몬스터 스펙
| 몬스터 | 행동 패턴 | HP | 기본 공격력 | 특수 공격력 | 용언 상호작용 |
|---|---|---|---|---|---|
| 거미 | 소환 시 십자형 거미줄 생성 후 접근, 거미줄 닿으면 슬로우 | 110 | 5(근접) | - | 파랑 I/O: 거미줄 차단·분리 / 파랑 X: 거미줄 절단 / 공통 V: 거미줄 중심이 범위 안이면 거미줄 소멸 |
| 멧돼지 | 준비 자세 후 돌진 | 150 | 5(평시 근접) | 10(돌진 명중) | 파랑 X: 돌진 경로 반전 / 파랑 I: 벽에 막혀 자체 피해 / 붉은 V: 돌진 중인 몹들 모아 폭발 |
| 부유정령 | 비행하며 랜덤 투사체 발사 | 90 | 5(투사체) | 5(붉은V 견인 시 3연발, 배율 없음) | 파랑 X: 탄환 궤도 교란 / 파랑 O: 탄환 봉인 |
| 분열슬라임 | 사망 시 2마리로 분열, 최대 2번(1->2->4) | 80 | 5(근접) | - | 파랑 O: 해당 공격을 받은 이후에 분열 안 함(영구지속) / 붉은 O: 규칙 무시하고 4마리로 강제 분열 / 공통 X: 분열 진행 중 해당 공격 받아 사망 시 분열 안 함 |
| 폭탄벌레 | 사망 시 폭발 | 80 | - | - | 파랑 O: 가둬진 채 폭발하며 범위 피해(몬스터에게 60피해) / 붉은 O: O가 깨지며 더 큰 범위 폭발(몬스터에게 40피해, 플레이어에게 15피해) |
| 뿔개미 (보류) | 꼬리로 연결되어 이동 | 85 | 5(근접) | - | 공통 일반 공격선: 연결고리 분리 / 파랑 X: 분리 + 스턴 / 붉은 X: 분리되어 반대 방향 이탈 후 재추적 |
| 인형(더미) | 공격&이동 안 함 | 1000 | - | - | - |

공용 접촉 피해(몸통 부딪힘)(인형 제외): **5**


## 기술 스택
- Vanilla JS + HTML5 Canvas
- 외부 라이브러리 없음
- 수학적 패턴 인식 (키 층/열 좌표 기반)
